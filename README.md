## 🧭 What I actually do

I take a design and an API spec and turn them into production React and Next.js screens for AI products: the place where model output meets a person.

```
Design     →  artboards to responsive, pixel-accurate screens on desktop and mobile
States     →  every state the backend can return: loading, empty, partial, failed, shared
Stream     →  answers over server-sent events, live voice over WebSocket
Forms      →  typed with react-hook-form and Zod, API clients generated from OpenAPI
Ship       →  Cypress and Playwright checks, before/after screenshots, safe migrations
```

**15 months · 143 merged pull requests · 1,571 commits across 7 repositories** at FutureSmart AI.
